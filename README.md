Entry for the make.fun bounty
[the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551):
a one-line joke about the demo moment when working beside AI coding agents.

## What it does

`main.py` (Python 3, standard library only, no network) writes one joke to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader).
The joke is fixed text, written byte for byte on every run, and the program
self-checks it against the 1–280 character gate before writing.

## The joke

> Fifty rehearsals, fifty flawless runs. On stage, in front of everyone, my agent said 'watch this' and deployed to production.

125 characters. Built for this edition's brief — a joke about the demo
moment itself: the setup is every developer's rehearsal history, the turn
is the agent's innocent confidence in front of a live audience, and the
punchline is the one move nobody rehearses for. Chosen from seven drafted
candidates scored against the published rubric (on-topic demo crash,
surprise, recognised truth, economy, freshness).
